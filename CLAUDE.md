# Kur Takip — instructions for Claude

This project was generated by the **ios-app-builder** skill and must keep following its coding rules.

## Before you change code
1. Read the rule files that apply to the change in `~/.claude/skills/ios-app-builder/references/rules/`
   (always `core.md`; then e.g. `swiftui.md`, `designsystem.md`, `i18n.md`, `testing.md`, `architecture.md`).
   If the skill isn't installed, the same rules are summarised below.
2. Look at an existing feature (e.g. `Packages/FeatureRatesList`) and follow the same structure.

## Non-negotiables (summary)
- Modules are local Swift packages under `Packages/`. `Feature*` depend on `Core*` only; features never depend on each other.
  Register a module with `scripts/modules.py` (or `tools/modules.py`), never by hand-editing `project.yml`.
- UI: `XRoute` (owns the `@Observable` ViewModel) + stateless `XScreen` (state in, events out). One `uiState` per ViewModel,
  built from immutable value types. Navigation structure lives in the app target (`Router`); features expose a Key and an Entry.
- Components: generic look in `CoreDesignSystem` (no strings), shared app components in `CoreUI`, feature-only UI in the feature.
  Features never use raw `TextField`, `Toggle`, `.alert`, or `Button("text")`.
- Strings: only in `Packages/CoreLocalization/.../<feature>.xcstrings`, keys prefixed `<feature>_`, every language
  (`tools/strings_tool.py`). Look them up with `table:` and `bundle: .localization`. Never hard-code user-facing text.
- No hard-coded colors or sizes: `KurTakipTheme.colors/spacing/typography`.
- No force unwraps, no `print`/`NSLog` (use `AppLogger`), no GCD, no `Task.detached`, no TODOs.
- Files ≤ 300 lines. Every ViewModel, repository and mapper has Swift Testing tests; every screen and component a ViewInspector test.
- Warnings are errors in every module. No lint baseline, no suppression without `// justified: <reason>`.
- Tests never type UI text: derive it with `localizedString(_:table:)` from CoreTesting.

## Quality gate (must pass before every commit)
```bash
tools/gate.sh .                  # whole project: build, SwiftFormat, SwiftLint, tests + coverage, rules, dead code
tools/gate.sh . CoreRepository   # one module while you work on it
swiftformat .                    # fixes formatting
```
